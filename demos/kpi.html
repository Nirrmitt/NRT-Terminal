Automated KPI Extraction from unstructured reports

Paste or edit a report, run the rule-based extractor, watch the schema validation accept or reject it, then explore the structured metrics in a dashboard built from everything you have extracted so far.

About this demo: a lightweight in-browser port of the repo's extraction and validation stage. The regex patterns and the date / churn 0–100 / NPS 0–100 checks follow src/extraction.py, including the repo's defaults of 0 when a metric is not found (turn on strict mode to reject instead). Everything runs in JavaScript on fictional sample reports or text you type; nothing is uploaded. Differences from the full repo: no PDF/TXT ingestion from data/raw (pdfplumber), no Pydantic, no SQLite storage (records live in this page until you reload), and the dashboard here is Chart.js rather than Streamlit + Plotly. The repo keeps its upserts keyed on source_file + report_date; this demo does the same. Only the patterns shown are supported, so other wordings simply will not match.
