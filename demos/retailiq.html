RetailIQ query preview & SQL safety check

Ask a retail question and get a read-only PostgreSQL SELECT preview, then see it pass through the same kind of safety guard the RetailIQ API applies before returning SQL. Paste your own SQL to see whether it would be accepted or rejected.

About this demo: this is a lightweight in-browser version. The real app (FastAPI + Streamlit + PostgreSQL) sends your question to an LLM (OpenRouter or OpenAI) to write the SQL, and it does not execute the SQL; there is no RAG either. Here there is no model: questions are matched against a small set of offline templates, so unusual phrasing will not be understood. The safety checks 1–4 below mirror the repo's regex-based is_safe_query(), which is a lightweight filter, not a SQL parser or a database permission system. The schema allow-list is a demo extra. The optional "Run on sample data" mode uses a small synthetic dataset and a handful of supported query shapes, not a database.
