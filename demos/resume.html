AI Resume Analyzer + EDA

Score how well a resume matches a job description using the repo's weighted model: 45% semantic similarity, 35% skill match and 20% experience relevance. Paste text or upload a TXT, PDF or DOCX file.

About this demo: this is a lightweight in-browser version. The full project uses SentenceTransformers (all-MiniLM-L6-v2) embeddings for semantic similarity and spaCy NER plus a skills dictionary for extraction. Here, TF-IDF cosine similarity replaces the embeddings and extraction is rule-based only (no NER), so scores will differ from the Python app, and TF-IDF tends to give lower similarity than embeddings do. The weights, skill list, experience parsing, thresholds and feedback rules follow the repo's config.yaml, parser.py and analyzer.py. Files never leave your browser: parsing happens locally and nothing is uploaded or stored.

How this compares to the full repo

  • Same: final = (0.45 × semantic + 0.35 × skills + 0.20 × experience) × 100; skill score = matched ÷ skills found in the JD (0.5 if the JD names none); experience score = similarity between the first three parsed experience entries and the JD (0.5 if none found); resumes under 50 words are rejected; match levels use the repo's code path (below 65 = Good, below 45 = Weak, otherwise Strong); the same feedback rules.
  • Different: TF-IDF (unigrams + bigrams, stop-words removed) instead of SentenceTransformer embeddings; no spaCy NER, so only the repo's 40-skill dictionary is detected; skills use a lookaround match so c++, ci/cd and node.js can match; PDF/DOCX text comes from pdf.js and mammoth.js rather than pdfplumber and python-docx.
  • Demo-only extras: the “years of experience” check and the skill-category chart (the repo does this kind of EDA in a notebook). Years are estimated from date ranges and phrases like “3+ years”.
  • The optional ×2 calibration (on by default, uncheck for raw TF-IDF cosine) is my own heuristic and not part of the repo.
  • No scores here are real benchmarks; they illustrate the scoring logic on the text you provide.
